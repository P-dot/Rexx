# References

The lab sequence follows the REXX tutorial material supplied for this project. Supporting sources are used to complement that sequence, including:

- Michael Cowlishaw, *The REXX Language: A Practical Approach to Programming*.
- Anthony S. Rudd, *Practical Usage of TSO REXX*.
- IBM z/OS / TSO/E REXX materials supplied with the project.

These sources support the REXX control-flow concepts documented here. The repository contains original lab work and does not redistribute the reference publications.
