# Theory — REXX Fundamentals

REXX is a high-level language widely used on IBM mainframe systems for scripting and automation. In this introductory lab the focus is intentionally limited to the language elements demonstrated by the source lesson and the executed exercise.

## Concepts demonstrated

### SAY
Writes text or evaluated values to the terminal.

### PULL
Reads input and assigns it to a variable.

### Variables
REXX allows values to be assigned directly to variable names. This lab uses `INP1`, `INP2` and `SUM`.

### Expressions
`SUM = INP1 + INP2` evaluates an arithmetic expression and stores its result.

## Why TSO/E matters
A REXX EXEC can be used interactively in the TSO/E environment, making it useful for operator, developer and system-administration automation. Later labs can extend this foundation into command execution, dataset processing and other z/OS services.
